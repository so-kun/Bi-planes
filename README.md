# Bi-Planes

レトロゲーム Bi-Planes をブラウザゲームとして再構築するプロジェクト。

- 2人対戦（1台のキーボード）の2D空戦ゲーム
- 自作フライトモデルによるリアルな操作感（失速・エネルギー管理）
- カップヘッド風レトロカトゥーンのグラフィック
- Web Audio による自己完結のサウンド

## 進め方

設計・デザイン・サウンドをディスカッションとサンプルで固めてから実装する。
決定事項は `docs/decisions.md`、経過は `docs/progress.md` に記録する。

詳細は `CLAUDE.md` および `.claude/rules/` を参照。
