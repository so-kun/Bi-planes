# Bi-Planes

レトロゲーム Bi-Planes をブラウザゲームとして再構築するプロジェクト。

- 2人対戦（1台のキーボード）の2D空戦ゲーム
- 自作フライトモデルによるリアルな操作感（失速・エネルギー管理）
- ヴィンテージのペン画＋水彩のアート（提供イラストをそのまま使用）
- Web Audio による自己完結のサウンド
- 古いフィルム風のポストエフェクト

## 動かす

```
npm install
npm run dev      # 開発サーバ。表示された URL をブラウザで開く
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果を確認
```

## 現在の状態: M3（仕上げ中）

起動するとオープニングが出ます。何かキーを押すか、パッドの ○A を押すとステージ選択に移り、
**1人で遊ぶ / 2人で対戦 / タイムアタック / フリープレイ**の4つと、**オプション**が並びます。

| 遊び方 | 内容 |
|---|---|
| 1人で遊ぶ | あなた 対 コンピュータ |
| 2人で対戦 | あなた 対 もう1人 |
| **タイムアタック** | **輪をくぐって10ステージの合計タイムを競う** |
| **フリープレイ** | **相手なし。一人で飛ぶだけ** |
| **オプション** | **音・見た目・ルール・機体の性能・パッドの割り当て** |

上下で遊び方を選び、Enter で決定・Esc で戻る。パッドならスティック上下で選び、**○A で決定・×B で戻る**。
コンピュータの腕前は**オプションの「コンピュータの強さ」**で決めます
（同じ設定を2か所に置くと、どちらが本当か分からなくなるため一本化しました）。

決定すると **READY? → 3 → 2 → 1 → GO!** の合図が出てから始まります。

二機が同じ空を飛び、撃ち落として得点を競う。**20点先取で勝ち**（オプションで変えられます）。
勝敗が決まったら **Enter（○A）でやり直し、Esc（×B）でタイトルへ**戻ります。

操縦桿と同じ向きです ―― **引く（下）と機首が上がります**（オプションで 1P・2P それぞれ逆にできます）。

| 操作 | 1P | 2P |
|---|---|---|
| **機首上げ** / 下げ | **S** / W | **↓** / ↑ |
| **全開**（押している間だけ。水温に注意） | E | Shift |
| ロール（正立 ⇄ 背面） | A / D | ← / → |
| 7.7mm 機銃（押しっぱなしで連射） | F | , |
| 20mm 機関砲 | G | . |

共通キー: 1〜5 フィルム強度（切／弱／既定／標準／強）、B BGM、M 消音、Tab 計器表示、Enter やり直し、**Esc 一時停止**

### 決定とキャンセル

どの画面でも**同じボタン**でそろえてあります。

| | キーボード | パッド |
|---|---|---|
| 決定・もう一度 | Enter | **○ A** |
| 取り消し・戻る | Esc | **× B** |
| **飛んでいる途中で一時停止** | Esc | **Start（＋／Options）** |
| タイムアタックのやり直し | R | **Select（−／Share）** |

パッドの ○A・×B は**飛んでいる間は 20mm と 7.7mm** なので、そのときは決定・取り消しとして
読みません。飛行中に抜けたいときは **Start（＋）** を押してください。

決着した瞬間に引き金を引いていても暴発しないよう、**一度ボタンから指を離すまで**
決定と取り消しは効きません。

### 一時停止

飛んでいる最中に **Esc / パッドの ＋（Start）** を押すと、その場で止まって
**「ゲームを終了しますか？」**が出ます。押した瞬間にタイトルへ戻る作りをやめました ——
押し間違えて試合が消えてしまうためです。

- 止めている間は**何も進みません**（機体・弾・気球・煙・開始の合図まで止まります）
- カーソルは**「いいえ、つづける」**から始まります。**＋ をもう一度押すだけで戻れます**
  （×B・Esc でも同じ）
- 戻るときは **GO!** が一瞬出てから動きだします。握り直す間を置くためです
- 1P・2P のどちらのパッドでも操作できます。タイムアタックとフリープレイでも同じです
- 勝敗が決まったあとは確認を挟みません（画面に戻り方が出ているので、そのまま戻ります）

### オプション

ステージ選択の**「オプション」**から入ります。変えたそばから効いて、**ブラウザに保存**されるので
次に開いたときもそのままです（`biplanes.settings`）。

**入口・ゲーム設定・コントローラー設定の3枚**に分かれています。
どの画面も **1P と 2P が同時に操作できます** —— カーソルは2本あり、それぞれのパッドが
自分のカーソルを動かします。

**ゲーム設定**（全体で1つ。どちらが変えても同じところに効きます）

| 項目 | 内容 |
|---|---|
| 音量 | 0 〜 100%（10 刻み） |
| BGM | 入 / 切 |
| **古いフィルム風の効果** | 切 / 弱 / 既定 / 標準 / 強 |
| **コンピュータの強さ** | **弱 / 普通（既定）/ 強。ステージ選択の左右と同じもの** |
| 勝ちに必要な点 | 10 / 15 / 20 / 30 / 50 |
| 7.7mm の威力 | 5 / 10 / 15（既定）/ 20 / 25 / 50。何発で撃墜かも併記 |
| **全開のパワー** | **150 / 180 / 220（既定）/ 260 / 300。落ち着く速度も併記（371〜532）** |
| **全開で水温が上がる速さ** | **上がらない / 10.0 / 7.0 / 5.0（既定）/ 3.5 / 2.5 秒で振り切れ** |

**コントローラー設定**（人ごとに持つので、**1P・2P の2列**で並びます）

| 項目 | 内容 |
|---|---|
| 機首の向き | 引くと上げ（既定・操縦桿と同じ）／ 倒すと上げ |
| スティックの遊び | 0.10 〜 0.40。中央の、倒していないとみなす幅 |
| **振動の強さ** | **切 / 弱 / 標準（既定）/ 強。選ぶとその場で試しに震えます** |
| **ボタンの割り当て** | **9 項目。その行で、割り当てたいボタンをそのまま押します** |

**「全開のパワー」**は押している間の推力です。巡航（速度 288）は変わらないので、
上げるほど「全開に切り替えたときの伸び」が大きくなります。

**「全開で水温が上がる速さ」**を「上がらない」にすると、**過熱そのものが起きません**
（水温計は 30% のまま）。冷える速さは変わりません。

**キーボードは既定で 1P の列**を担当し、**Tab で 2P の列**に移せます。パッドが1台しか
なくても 2P 側を組めるようにするためです（そのときは割り当ても1台目のパッドで押して決めます）。
2P の列は、2台目のパッドがつながっているか、キーボードが 2P 側にいるときだけカーソルが出ます。

**機首の向き**はその人の**キーボードとパッドの両方**に効きます。

割り当てを変えられるのは **7.7mm・20mm・ロール左・ロール右・全開・決定・取り消し・中断・やり直し**の
9 つです。**その行にカーソルを合わせて、割り当てたいボタンを押すだけ**です（決定を挟みません）。

すでに別の操作に付いているボタンを選んだときは、**同じ場面で使う操作とだけ入れ替わります**。
飛んでいる間に読むもの（7.7mm・20mm・ロール・全開）と、画面で読むもの（決定・取り消し）は
別の集まりなので、**20mm と決定が同じ○A に乗っていても構いません** —— 飛んでいる間は決定を
読まず、画面では 20mm を撃たないからです。中断とやり直しはどちらの場面でも読むので、
両方とぶつかります。入れ替わるのはその人のパッドの中だけで、もう一方には触りません。

機首のスティック（左スティック上下・十字キー）とキーボードのキーそのものは変えられません。
十字キーの上下は一覧を動かすのに使うので、割り当てにも入りません。

**7.7mm の威力**は一発あたりの数字で、HP は 100 なので `15` なら 7 発で撃墜です
（画面には「15（7 発で撃墜）」と両方出ます）。20mm は一撃撃墜のまま変わりません。
弱くすると当てる回数が増えるぶん、**落とす前に相手のエンジンや舵を潰しきる**戦い方になります
（性能低下は一発ごとに進むので、5 発も当てればエンジンは下限に届きます）。

### 振動

パッドが震えます（Chrome・Edge。**Safari では何も起きません**）。

| 出来事 | 手ざわり |
|---|---|
| 7.7mm を受けた | 短く弾く（110ms） |
| 水温が赤帯に入っている | 止まらない低いうなり。踏み込むほど強くなる |
| 撃墜された | 手に残る一撃（420ms） |

弾は高い周波数の小さな錘、爆発は低い周波数の大きな錘を回すので、同じ強さでも別のものに感じます。
震えるのは**当たった本人のパッドだけ**です。強さはオプションの「振動の強さ」で
1P・2P それぞれ変えられます。

### うまく動かないとき

**フィルム風の効果が出ない**場合、ブラウザが WebGL を使えていない可能性があります。
その場合は起動時に画面下へ但し書きが出ます。**Tab** を押すと計器表示の最下段に
描画方式（WebGL / Canvas）と GPU 名が出るので、そこでも確かめられます。
Chrome なら 設定 → システム →「ハードウェア アクセラレーションが使用可能な場合は使用する」を入に。

**立ち上がりが遅い**のは絵を読み込んでいるところです（合わせて 9MB ほど）。
`BATTLE PLANES` の下に進み具合が出ます。読めなかった絵があれば、どれが欠けたかを
画面下の帯に出します —— そこだけ欠けた見た目になりますが、遊ぶことはできます。

**何かおかしくなったとき**は、画面下に赤い線の帯でエラーが出ます（クリックで消せます）。

### コンピュータ操縦

タイトルで選ぶほかに、**対戦中に切り替える**こともできます。
**C キー**が 2P、**V キー**が 1P で、押すたびに 切 → 弱 → 普通 → 強 → 切 と巡回します。
フリープレイで V を押せば、一機が飛ぶ様子を眺められます。

CPU は人と同じものしか出しません ―― 機首の引き具合・ロール・スロットル・引き金の5つだけ。
機体の中身は触らないので、人に出せない動きにはならず、失速も墜落も同じように起こります。

### タイムアタック

**10ステージの合計タイムを競う**モードです。敵も武装も出ません。

番号の付いた輪が空に浮かぶので、**番号順に**くぐります。順番どおりでない輪は消えません。

輪には**くぐる向き**があります（**塗りつぶした矢印**と、潰れた楕円の向きで分かります）。
その向きに輪を横切ったときだけ通過で、上から乗っても逆から抜けても通りません。

**自爆すると +3.00 秒**です。落ちてもすぐ出撃位置に戻れるので、代償は時間で払います
（画面には落ちた場所に「+3.00」が出て、計器の下に自爆の回数も出ます）。

エンジン音と**パッドの振動も対戦と同じ**です。全開にすると音が上がり、水温が赤帯に入ると
エンジンが息切れしはじめて、パッドが低くうなります（対戦より水温を見るモードなので、
音と手ざわりがそのまま目安になります）。

計器盤は対戦と同じ真鍮の板で、出すものだけ違います:

| | 見かた |
|---|---|
| TIME | 合計タイム。窓の隅に「いま何ステージ目か」 |
| RINGS | このステージののこりの輪 |
| 丸い計器 | **水温**。全開の使いどころがタイムを決めるので、対戦よりよく見ます |

全10ステージのコースは手で組んであり、進むにつれて必要な機動が増えます ――
上昇と下降 → 折り返し → 宙返り → スプリットS → インメルマンターン → 一周 → 総仕上げ。

**10ステージの合計がいちばん短いもの**がハイスコアとして残ります（ブラウザに保存されます）。

**R**（パッドは Select）で今のステージをやり直し、**Esc**（パッドは ＋）で一時停止します。

### フリープレイ

相手を出さず、一人で飛ぶだけのモードです。勝ち負けは付かず、時間の制限もありません。
気球は出るので、撃った数だけ計器に「気球 n」と出ます。落ちればそのまま再出撃します。

### 計器盤

画面の左右上に、**真鍮枠の計器盤**が1人につき1枚出ます。

| | 見かた |
|---|---|
| SCORE | 得点。窓の隅に小さく `/ 20`（勝ちに必要な点。オプションで変わる） |
| HEALTH | 体力。8目盛り。減ると右から消え、最後に赤だけが残る |
| 盾 | 1P / 2P の色分け |
| 丸い計器 | **水温**。全開にすると上がり、離すとゆっくり下がる |
| 弾 | 20mm の残弾。撃つと沈んで暗くなる |

### 全開と水温

全開は速く、逃げるときや登るときの切り札になります（巡航 288 に対して 454）。
ただし**押している間ずっと水温が上がります**。

- 冷えきりから**赤帯まで約3秒**、**振り切れまで約5秒**
- 振り切れたまま吹かし続けると、**1.1秒ごとにエンジンが傷みます**（弾を受けたのと同じ扱い。
  黒煙が出て、機体の性能も落ちます）。そのまま押し続ければ 13 秒ほどで自滅します
- 離せばゆっくり下がります。赤帯を出るまで約4.5秒、冷えきるまで約13秒
- 赤帯に入ると**針が赤くなり、エンジンが息切れしはじめます** ―― 燃え損ねて音が飛び、
  金属を叩くようなノッキングが回転に合わせて混じり、蒸気がうっすら噴きます。
  **踏み込むほど悪くなる**ので、振り切れが近いことが耳で分かります。
  パッドが震えるのもここからです。スロットルを離しても、赤帯を出るまでは続きます

上げ下げの比はおよそ 2.5:1 なので、全開でいられるのは時間の3割弱までです。

### 画面の左右はつながっています

右端から出ると左端から出てきます（本家どおり）。出しろは機体の半分なので、
**姿が完全に消えている時間はありません** —— 右端で隠れきった瞬間に左端から現れます。
**弾も同じところで折り返します。** 7.7mm の射程は一周より短いので、
撃った弾が回り込んで自分に当たることはありません。

### 地面と街

地面は**場所によって高さが違います**。もとは一本の水平線で、中央の街のところが
屋根の高さの壁になっていました（街の上を飛ぶと、何もない空中で墜ちる）。

**街の建物には当たり判定がありません。** 尖塔も煙突も屋根も背景の絵として通り抜けるので、
**街の中へ降りて、建物の間を縫って飛べます**。地面は建物が立っている谷底＝道の高さです。

街の中央では飛べる高さが 53px 下がりました（612 → 665）。右端だけは手前の丘が
持ち上がるので、そこに合わせて地面も上がっています（1280 で 615）。

数値は `src/config.ts` の `GROUND`。点と点の間は直線でつなぎます。

### 得点

| | 点 |
|---|---|
| 相手を撃墜 | 3 |
| 相手が自滅（激突・焼き付き）・**無傷のまま** | 1 |
| 相手が自滅（激突・焼き付き）・**傷ついた機体で** | **3（撃墜と同じ）** |
| 気球 | 1 |

**傷ついた機体で自滅すると、撃墜と同じ 3 点が相手に入ります。** 撃ち落とされる前に
わざと落ちて、相手に入る点を減らす —— という逃げ道を塞ぐためです。無傷のまま落ちたときは
今までどおり 1 点です（見分けは体力の帯そのもので、目盛りが欠けていれば「傷ついた機体」。
金色の気球で完全に直れば、また無傷に戻ります）。

**地面への激突とエンジンの焼き付きは同じ扱い**です。焼き付きだけ 0 点のままだと、
そちらが「点を与えずに死ねる道」として残ってしまうためです
（焼き付きは体力が尽きて起きるので、実際には必ず 3 点になります）。

**金色の気球**（専用の絵）を撃つと自機が直る（HP と、被弾で鈍った性能の両方）。
負けている側の逆転手段なので、終盤ほど価値が上がる。

点が入ると、**入ったその場所に「+3」が浮かびます**（入れた側の色で）。
計器の数字だけでは、撃墜で入ったのか気球で入ったのかが分からないためです。

撃墜されると 2.4 秒後に再出撃し、そこから **2秒は無敵**です。無敵の間は機体が
点滅して透け、弾がすり抜けます。出てきたところを撃たれて何もできないのを防ぐためです。

**当たり判定は弾の通り道で見ます。** 7.7mm は 60fps でも1コマに 25px 進むので、
その瞬間の位置だけで見ると機体をまたいで通り抜けていました。前のコマと今を結んだ線分で
見るようにしたので、フレームが落ちている環境でも取りこぼしません。
**機体どうしはぶつかりません**（本家にも無く、すれ違いざまの読み合いが濁るため）。

**傷むと機体が震えます。** 傷が深いほど大きく震えるので、煙の色（黒＝エンジン／白＝舵）と
合わせて、相手をどこまで追い込めているかが見た目で分かります。震えるのは見た目だけで、
当たり判定は動きません。

BGM は最初のキー入力（またはクリック）で自動的に鳴りはじめます。B キーで止められます。

**ステージ選択には別の曲**（ニュース映画風の行進曲）が流れ、対戦やタイムアタックに入ると
対戦の曲に切り替わります。カーソルを動かす・腕前を変える・決定する・戻るのそれぞれに音が付きます。

### ゲームパッド

PlayStation / Switch Pro / Xbox などの**標準配列のパッド**に対応しています。
つないでボタンを一度押すと認識されます（ブラウザが、押されるまでパッドを見せない決まりのため）。

| 操作 | パッド |
|---|---|
| **機首上げ** / 下げ | 左スティックを**引く**（下）で上げ、倒す（上）で下げ。十字キーも可 |
| **全開**（押している間だけ） | R2 / ZR |
| ロール（正立 ⇄ 背面） | **L / R**（L1・R1、Switch は L・R） |
| 7.7mm 機銃 | ×／B（押しっぱなしで連射） |
| 20mm 機関砲 | ○／A |
| 一時停止（終了の確認） | Start（＋／Options） |
| メニューでの決定 / 取り消し | ○／A ・ ×／B |

**割り当てはオプションで、1P・2P それぞれ変えられます**（機首のスティックと十字キーを除く）。

スティックは**倒した量がそのまま舵の効き**になります。そっと引けば大きな輪で、
倒し切れば小さな輪で回れます。キーボードと同時に使えます。

標準配列でないパッドは、ボタンの並びが機種ごとに違って別の操作に化けるため使いません。
つないでいるパッドが認識されるかどうかは `samples/gamepad-check.html` で確かめられます。

**画面の左右はつながっています。** 右端から出ると左端から出てきます。
端からの出しろは**機体の半分**なので、右端で隠れきった瞬間に左端から現れます ――
姿が消えている時間はありません。

**背面飛行では上下の操作が入れ替わります**（機体基準）。宙返りで左向きになると背面に
なるので、正立に戻すにはロールが要ります。実機と同じ挙動です。

煙は損傷したときだけ出ます。**エンジンをやられると黒煙、舵をやられると白煙**。
どこが壊れるかは**当たりどころ**で決まります ―― 機首側に当てればエンジン、
尾翼側に当てれば舵。相手の煙の色を見れば、自分が何を潰したのかが分かります。

## 調整

飛行の数値は `src/config.ts` に集約してあります。ブラウザを立ち上げずに確かめるには:

```
node tools/flight-probe.mjs
node tools/flight-probe.mjs --thrust=300   # 全開のパワーを変えて測る
```

水平飛行の速度、失速する速度、宙返りの大きさ、急上昇からの立て直しを一度に出します。
最後に、オプションで選べる全開のパワーごとの速度も並べます —— オプション画面が
併記している速度はこれと同じ計算から出しているので、両者が食い違うことはありません。

## 公開する（Vercel）

静的サイトとしてビルドされるので、そのまま Vercel に載せられます。`vercel.json` は用意済みです。

**ダッシュボードから:**
1. https://vercel.com/new でこのリポジトリを Import
2. Framework は Vite が自動で選ばれる。Build Command / Output Directory も `vercel.json` の
   指定（`npm run build` / `dist`）が使われるので、そのまま Deploy
3. ブランチを指定する場合は Settings → Git → Production Branch で切り替える

**CLI から:**
```
npx vercel          # プレビュー環境へ
npx vercel --prod   # 本番へ
```

ビルド結果は約 9.4MB です。うち 3.5MB はタイトル周りの絵2枚（オープニングの完成図と
ステージ選択の背景。どちらも 1280x720 の PNG）で、気になるなら書き出しを JPEG に
変えるだけで大きく減らせます。原本イラスト（`assets/art/original/`、34MB）は実行時に
使わないので、`vite.config.ts` のプラグインでビルド後に取り除いています。

## 素材

原本は `assets/art/original/` に無加工で置き、加工物は次で再生成できます:

```
python3 tools/cutout.py          # 紙地を抜いて透過 PNG に
python3 tools/extract_smoke.py   # 煙のひと粒を切り出す
```

ゲームで使うスプライトは長辺 640px（気球は 512px）に縮めて書き出しています。表示幅が 102px
なので原寸の 1536px は過剰なためです。画質を上げたくなったら `tools/cutout.py` の
`RUNTIME_MAX_WIDTH` を変えて作り直してください。原本は無加工のまま残してあります。

タイトル周りの絵（オープニングの完成図・ステージ選択の背景）は切り抜かず、画面の大きさ
（1280x720）に合わせるだけです。オープニングの絵に描かれている "PRESS START" は、
自分で明滅させる文字と重なるので消しています（同じ行の海を横からずらして埋めている）。
