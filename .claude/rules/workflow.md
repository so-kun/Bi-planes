# 進め方のルール

## フェーズ

1. **ディスカッション期（現在）**: ゲームシステム / UI・キャラデザイン / 効果音・BGM の3点を、
   「提案 → サンプル提示 → ユーザー採用」の順で固める。採用されるまで次に進まない。実装はしない。
2. **実装第1弾**: 1P のみ操縦できるプレイテスト版（気球・的だけの空）。操作感と効果音の確認が目的。
3. **実装第2弾**: ユーザーがプレイテストに納得したら、2P対戦・スコア・演出を実装して完成させる。

## Git 運用

- ベースブランチは `main`。作業ブランチを切って PR を作成して進める
- コミットメッセージは日本語または英語で、変更の意図がわかるように書く
- サンプル類は `samples/` に置く（ゲーム本体のコードとは分離する）

## 記録

- 決定事項は `docs/decisions.md` に追記（決定日・内容・理由）。未決事項は「検討中」として同ファイルに列挙
- 各セッションの経過は `docs/progress.md` に追記（日付・やったこと・次にやること）
- ゲーム仕様の詳細は `docs/game-design.md` に集約し、決定に合わせて更新する
