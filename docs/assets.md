# アセット仕様

ステータス: **素材の取り込み完了**（2026-08-12）

ユーザー提供のイラストをそのままゲーム素材として使う。コード描画（SVG/Canvas）は廃止する。

## 置き場所

```
assets/
  art/
    original/            ← 提供されたイラストの原本（無加工で保存。差し替え時の元データ）
    planes/              ← 機体スプライト（背景透過 PNG）
    smoke/               ← 煙のスプライト
    bg/                  ← ステージ背景
```

原本は必ず `original/` に残す。加工物は原本から再生成できるようにする。

## 取り込み済みのファイル

すべて `tools/cutout.py` と `tools/extract_smoke.py` で原本から再生成できる。原本は書き換えない。

| ファイル | 状態 |
|---|---|
| `planes/plane-blue.png` | 紙地を抜いた透過 PNG（1536×1024） |
| `planes/plane-red.png` | 同上 |
| `planes/plane-blue-smoke.png` | 同上（煙あり。見た目の基準用） |
| `smoke/puff-dark-01..04.png` | 濃い煙のひと粒（約 200px 四方） |
| `smoke/puff-light-01..04.png` | 薄い煙のひと粒（同上） |
| `planes/plane-blue-top2.png` / `plane-red-top2.png` | 上面図。ロール 90度 の中間コマ |
| `planes/plane-blue-under2.png` / `plane-red-under2.png` | 下面図。ロール 270度 の中間コマ |
| `props/baloon.png` | 気球（撃ち落とす的） |
| `bg/stage-sunset.png` | 1280×720 にリサイズしたステージ背景 |

### 上面図・下面図は煙なしの差し替え版を使う

初版（`plane-*-top.png` / `plane-*-under.png`）は煙が描き込まれていて、しかも煙が上翼の上に
重なっていたため自動では抜けなかった。ロールの途中で煙が現れてしまうため、
**煙なしの差し替え版（末尾に 2 が付くファイル）を使う**。初版の原本は参考として `original/` に残す。

### 書き出しサイズ

ゲームで使うスプライトは長辺 **640px**（気球は 512px）。機体の表示幅が 102px なので、
原本の 1536px は過剰で、そのままだとビルド結果が 60MB になってしまう。
高解像度の画面で拡大されることを考えても 640px で足りることを確認済み。
`tools/cutout.py` の `RUNTIME_MAX_WIDTH` で変えられる。原本は無加工のまま残す。

**原本（`original/`、34MB）は実行時に使わない。** publicDir はまるごとコピーされるため、
`vite.config.ts` のプラグインでビルド後に `dist/art/original` を取り除いている。

### 切り抜きの仕組み

紙地は画像の縁とつながった塊としてまとめて抜く。機体の内側にあるクリーム色の塗装面は
黒い輪郭線で囲まれていて縁とつながらないため、誤って抜けない。
支柱の間などの囲まれた紙の隙間は、面積が小さいか「紙との平均距離」が小さいものを抜く
（実測で、残った紙地は 8〜10、機体の塗装面は 15〜21 と分離できる）。
プロペラの回転ブラーのような淡い線は、距離に応じた半透明として残している。

## 原本に対して当初想定していた要件（参考）

### 1. 機体（背景透過 PNG）

| ファイル | 内容 |
|---|---|
| `planes/plane-blue.png` | 青塗装の機体（P1 または P2） |
| `planes/plane-red.png` | 赤／クリーム塗装の機体（もう一方） |

- **向き**: 原本は機首が左。ゲーム内では水平反転して使うので、原本のままでよい
- **背景透過が必須**。提供画像はベージュの紙地に描かれているため、切り抜きが要る
  （紙地が均一なので、原本さえあればスクリプトで自動的に抜ける。手作業も可）
- **煙は含めないこと**。煙入りの絵は「見た目の基準」としては最高だが、素材として焼き込むと
  被弾状況に応じて煙の量を変えられない。煙は別スプライトで後述のとおり出す
- 解像度: 長辺 1500px 程度あれば十分（ゲーム内表示は 200〜260px 幅を想定し、縮小して使う）

### 2. 煙（背景透過 PNG）

| ファイル | 内容 |
|---|---|
| `smoke/puff-light-01..04.png` | 白煙のひと粒（提供画像の煙のタッチを踏襲した、もこもこの塊） |
| `smoke/puff-dark-01..04.png` | 黒煙のひと粒 |

- 提供された煙入り画像の煙は、この「ひと粒」を連続で出すことで再現する
- 1粒あたり 200〜300px 四方。4種類あると繰り返し感が消える

### 3. 背景

| ファイル | 内容 |
|---|---|
| `bg/stage-sunset.png` | 提供された夕暮れの町のステージ背景 |

- 16:9。ゲームの論理解像度 1280×720 に合わせて使う（原寸 1366×768 のままでも可）
- 将来ステージを増やす場合は `stage-<名前>.png` で追加する

## 加工が必要な理由（背景透過）

提供画像はいずれも紙地の上に描かれている。ゲームでは機体を空の上に重ねるので、
紙地を抜いた透過 PNG が必要になる。**原本のファイルさえリポジトリに入れば、こちらで抜ける。**

## スプライトの扱い（実装メモ）

- 機体は1枚のスプライトを**回転**させて機首上げ／下げを表現する（アニメーション不要）
- プロペラは原本に回転ブラーが描き込まれているので、そのまま使える。
  スロットル段階でブラーの濃さを変えたい場合は、プロペラだけ別レイヤーに分ける
- 被弾すると煙のパーティクルを機首から出す。HP が下がるほど密度と黒さを上げる
- 撃墜時は機体を回転させながら落下させ、黒煙を濃く出す

## フィルム風エフェクトとの関係

提供イラストは既に古びた質感を持っているため、`docs/film-effect.md` のフィルム処理は
**強度を落として**かける想定（グレイン・縦キズ・ゲートウィーブは残し、セピア寄せとブラーは弱める）。
最終的な強度はスプライトを載せた画面を見て決める。
