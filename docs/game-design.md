# ゲームデザイン仕様（提案版）

ステータス: **M2 実装済み**。決定の正本は docs/decisions.md。
ここに「提案」と書かれた数値だけが未確定で、それ以外は実装に反映済み。

## コンセプト

本家 Bi-Planes の「シンプルな操作で生まれる空戦の駆け引き」に、
エネルギー管理（スロットル）と武装選択（7.7mm / 20mm）のレイヤーを1枚だけ足す。
見た目は1930年代カートゥーン（カップヘッド風）。

## フライトモデル（自作）

機体は位置・速度ベクトル・機首角を持ち、毎フレーム4つの力を積分する:

- **推力**: スロットル段階に応じて機首方向に加わる
- **重力**: 常に下向き
- **揚力**: 対気速度に比例して機体上方向に働く。失速速度未満で急減
- **抗力**: 速度の2乗に比例して減速。迎え角が大きいほど増える

これにより「急上昇 → 速度低下 → 失速 → 機首が落ちてきりもみ → 速度回復で立て直し」が自然に生まれる。

## 操作（1台のキーボードで2人）

| 操作 | P1 | P2 |
|---|---|---|
| 機首上げ / 下げ | S / W | ↓ / ↑ |
| スロットル（押している間だけ全開） | E | Shift |
| **ロール（正立 ⇄ 背面）** | **A / D** | **← / →** |
| 7.7mm 発射 | F | , |
| 20mm 発射 | G | . |

- スロットル: **巡航と全開の2段**。全開はボタンを押している間だけで、離すと巡航に戻る。
  3段階の切替式は、操作の手数の割に効果が読みにくかったため変更した（2026-08-12 決定）。
  **全開の推力はオプションで 150〜300 に変えられる**（既定 220・速度 454）。巡航は据え置き
- **全開には水温という代償がある**（2026-08-13 試行）。押している間は計器盤の水温計が上がり、
  赤帯で振り切れたまま吹かし続けるとエンジンが傷む。**上がる速さはオプションで変えられ、
  「上がらない」にすれば過熱そのものが起きない**。詳細は decisions.md
- **赤帯に入るとエンジンが息切れしはじめる**（2026-08-15 改定）。失火で音が飛び、
  回転に合わせたノッキングが混じり、蒸気がうっすら噴く。**踏み込むほど悪くなる**ので、
  振り切れが近いことが耳で分かる。パッドの振動もここから始まる。冷えて赤帯を出るまで続く

### ゲームパッド（2026-08-12 決定）

**標準配列（mapping === 'standard'）のパッド専用**。PlayStation / Switch Pro / Xbox など。
標準でないパッドは並びが機種固有で、番号をそのまま読むと別のボタンが操作に化けるため使わない。

| 操作 | パッド | 標準配列の番号 |
|---|---|---|
| 機首上げ / 下げ | 左スティックを引く／倒す・十字キー下／上 | 軸1 / ボタン13・12 |
| 全開（押している間だけ） | R2 / ZR | ボタン7 |
| **ロール** | **L / R** | ボタン4 / 5 |
| 7.7mm | × / B | ボタン0 |
| 20mm | ○ / A | ボタン1 |
| **一時停止（終了の確認）** | **Start / Options / ＋** | ボタン9 |
| **やり直し**（タイムアタック） | **Select / Share / −** | ボタン8 |
| **決定・もう一度**（飛行中以外） | **○ / A** | ボタン1 |
| **取り消し・戻る**（飛行中以外） | **× / B** | ボタン0 |

- **決定は ○A、取り消しは ×B**（2026-08-13 決定）。どの画面でも同じ。
  ただし武器と同じボタンなので、**飛んでいる間は決定・取り消しとして読まない**。
  飛行中に抜けたいときは Start（武器と重ならない）。詳細は decisions.md
- **ロールは肩ボタン**に置く。スティック左右に置くと、機首を引きながら旋回したときに
  スティックが斜めになってロールが暴発するため
- **機首はアナログ**。倒した量がそのまま舵の効きになる。飛行モデルは元から連続値を
  受け取る作りなので、キーボードの3値（引く／中立／押す）より細かく操れる。
  十字キーは倒し切りとして扱う
- キーボードと同時に使える。両方触っている場合は深く入れているほうを採る
- ボタンの状態は**毎フレーム読みに行く**。ブラウザのイベントに頼らないので、
  キーボードで起きた「押しっぱなしが残る」問題が原理的に起きない

### ロール

- 押すと機軸まわりに 180度 回り、正立と背面が入れ替わる（0.85秒）
- 左右のキーで回る向きが変わる。左は下面図を、右は上面図を見せながら回る。
  どちらも 180度 なので結果は同じで、回り方の見た目だけが変わる
- 見た目は上面図・下面図を中間コマとして補間する（0°側面 → 90°上面 → 180°側面反転 → 270°下面）
- 背面飛行中の操作は**機体基準**（実機と同じ。背面では画面上の上下が逆になる）で確定。
  背面のほうが機首を下げやすい＝急降下しやすい、という駆け引きが生まれる

## 武装

| | 7.7mm 機銃 | 20mm 機関砲 |
|---|---|---|
| ダメージ | 15（撃墜まで7発）。**オプションで 5〜50 に変えられる** | 100（一撃撃墜。変えられない） |
| 弾速 | 1500 px/秒 | 600 px/秒 |
| 弾道 | **直線**。重力の影響を受けない | **山なり**。重力 430 px/秒² で落ちる |
| 射程 | 約 765px＝画面幅の **60%**（寿命 0.51秒） | 約 480px＝画面幅の **37%**（寿命 0.80秒） |
| 連射速度 | 毎秒約11発 | 単発、装填2.5秒 |
| 弾数 | 無限（連射しすぎで過熱ゲージ→一時発射不能、は検討中） | **5発。一試合を通しての持ち弾**（撃墜されても補充されない） |
| 発射炎 | 小さく速い閃光（0.085秒） | 大きな橙の炎（0.17秒）＋白い発射煙 |

弾速・重力の数値は 1280×720 の論理解像度基準。プレイテストで詰める。
射程は必ず 7.7mm > 20mm になるようにする（20mm は「懐に飛び込んで当てる」武器）。

**20mm は一試合を通して 5 発**（2026-08-15 改定）。撃墜されても補充されない ――
リスポーンで戻していたころは「撃ち切ったら落ちて補充する」という手が成立していた。
配り直すのは試合の初め（`Plane.rearm()`）だけで、やり直しでは 5 発に戻る。

**当たり判定は線分で見る**（2026-08-15 改定）。7.7mm は 60fps でも1フレームに 25px 進み、
機体の判定半径（33px）に対して無視できない。フレームが落ちればさらに飛ぶので、
その瞬間の位置だけで見ると機体をまたいで通り抜ける。
**前のフレームと今を結んだ線分**が判定の円に触れたかで見る（`src/collision.ts`）。
相手も動いているので、線分は**相手から見た動き**（弾の動き − 相手の動き）で作る。
輪くぐり（`src/objects/Rings.ts`）と同じ考え方で、あちらは「面を横切ったか」、こちらは「円に触れたか」。

| 判定の中を通った弾のうち、当たった割合 | 静止した相手 | 正面から突っ込む相手 |
|---|---|---|
| 60fps | 98% → **100%** | 96% → **100%** |
| 30fps | 90% → **100%** | 81% → **100%** |
| 20fps（`dt` の上限） | 71% → **100%** | 54% → **100%** |

**機体どうしの当たり判定は無い。** 本家にも無く、すれ違いざまの読み合いが濁るため。

### 得点の吹き出し（2026-08-15 追加）

点が入った**その場所**に「+3」を出し、1.1 秒かけて浮かせながら消す。
色は入れた側の色（1P は赤、2P は青）。

計器盤の数字だけでは、撃墜で入ったのか気球で入ったのかが分からない ――
落ちた機の上、割れた気球の上、地面に落ちた場所と、出るところで理由が読める。
タイムアタックでも同じ仕掛けを使って、自爆の「+3.00」を出している。

## 爆発

火の玉・燃え残り・黒煙・土煙は、**提供イラストの煙の絵を色染めして**作る。別の絵を用意すると
絵柄が浮くため。染めるとインクの輪郭線まで同じ色になるので、元絵を掛け合わせて線の濃さだけ戻している。

| | 空中撃墜 | 地面への激突 |
|---|---|---|
| 閃光 | 0.13秒・機体幅の0.8倍 | 0.15秒・機体幅の0.72倍 |
| 衝撃波の輪 | 円 | 横長の楕円（地面に沿う） |
| 火の玉 | 全方位に10個 | 上半分に8個 |
| 土煙 | なし | 左右に8個、横へ広がる |
| 黒煙 | 遅れて膨らみ約2〜3秒残る | 同左（やや多め） |
| 破片 | 11個、重力で放物線 | 8個、上方向中心 |

## 耐久・ダメージ

- HP 100。被弾で減少
- 被弾ごとに「エンジン出力」か「舵の効き」のどちらかが鈍る。
  エンジンは 1.0 → 0.55、舵は 1.0 → 0.50 まで、1発あたり 0.09 / 0.10 ずつ落ちる
- 落ちた分だけ煙が濃くなる（エンジン＝黒煙、舵＝白煙）

### 煙の設計（確定・2026-08-12 改定）

- **通常飛行では煙を出さない**（当初は白い航跡を引いていたが、常時出ていると画面が煩わしいため廃止）
- **損傷したときだけ煙を出し、色で当たりどころを示す**:
  - **エンジン損傷 → 黒煙**
  - **操作系（舵）損傷 → 白煙**
- 傷が深いほど煙の間隔が詰まる。両方やられていれば黒と白の両方が出る
- 相手の煙の色を見れば、エンジンをやったのか舵をやったのかが分かる
- 性能低下がエンジンと舵のどちらに出るかは、**当たりどころで決まる**（2026-08-12 決定）。
  被弾点を機軸に射影し、機首側ならエンジン、尾翼側なら舵。
  狙って壊し分けられるようになり、相手の煙の色で結果が読める
- **エンジンが深く傷むと火が出る**（2026-08-15 追加）。**2発目から**炎が立ち、
  傷むほど長く太くなる。炎は風に流されて後ろへ伸び、ひどくなると白熱した芯と火の粉が混ざる。
  炎は機体の奥・芯だけ手前に描く（機体の形を潰さないため）。数値は `FIRE`（src/config.ts）、
  見本は `samples/engine-fire-sample.html`
- 撃墜されると機体は煙を引いて落下 → 爆発。2.4秒後に自陣側から HP 全快でリスポーン（`PLANE.respawnDelay`）

## コンピュータ操縦（2026-08-12 決定）

**AI は人と同じものしか出さない** ―― 機首の引き具合・ロール・スロットル・7.7mm・20mm の5つ。
機体の中身を直接いじる近道は作らない。人に出せない動きにならず、失速も墜落も同じように起きる。

### 考え方

毎フレーム「機首をどこへ向けたいか」を1つの角度に決め、そこへ舵を切るだけ。
向けたい先の決め方に優先順位がある:

1. **地面が近い** → 上を向く。判断は「今の高さ」ではなく **1.1秒先の高さ**で行い、
   そこが地面から 150px 以内なら引き起こす。地面の高さは場所によって違うので、
   **行き先の x での地面**で見る。今の高さだけで見ると、
   突っ込んでいる最中は手遅れになる（宙返りの半径が 135px あるため）
2. **失速している** → 下を向いて速度を取り戻す
3. それ以外 → 狙う相手（敵機か気球）の**未来位置**へ向ける。
   ただし**狙う高さには底がある**（地面から 150px）。
   地面すれすれの相手を追って一緒に突っ込まないようにするため

1 と 2 を最優先にしないと、AI は戦う前に墜ちる。

### 失速させない

舵を引くと迎え角が増えるので、**失速角の 0.8 倍を超えたら舵を緩める**。
逆向き（迎え角を減らす向き）の舵は妨げない。
速度で加減する案も試したが効かなかった ―― 失速を決めているのは迎え角そのものなので、
そちらを直接見るほうが正しい。

### ロールの使い方

実機と同じ理由で使う。機首を回すのに「押す」より「引く」ほうが素直なので、
押し続けることになる場面（誤差が 0.7 ラジアンを超え、かつ押し方向）では背面に返して引きに変える。
ただし地面や失速から逃げている最中は、回っている余裕がないので我慢する。

| 何もしない相手への得点 | 46 | 85 | 95 |
| CPU 同士の決着数 | 3試合 | 3試合 | 7試合 |

### 狙う相手の選び方

- 基本は敵機
- 傷んでいて（HP 60 未満、または性能が 0.85 未満）金色の気球が浮いていれば、そちらへ
- 敵機が撃墜されている間は、いちばん近い気球へ

### 切り替え

キー1つで巡回する（切 → 弱 → 普通 → 強 → 切）。**1P = V、2P = C**。
2P を任せれば1人で遊べる。フリープレイで 1P を任せれば、一機が飛ぶ様子を眺められる。

## タイトル画面と開始の合図（2026-08-12 決定・2026-08-13 改定）

起動するとまず**オープニング**が出る。いただいた完成図（`opening-title.png`）を
そのまま一枚で出す画面で、下部に **PRESS ENTER KEY  OR  ○ A BUTTON** が明滅する。
何かキーを押すか、パッドの ○A（または Start）で**ステージ選択**へ移る。
パッドをどのボタンでも通す作りにすると、ステージ選択から ×B で戻った直後に
また進んでしまうため、ここだけは絞ってある。

ステージ選択の背景は、オープニングからロゴと機体を除いた空だけの絵
（`opening-background.png`）。同じ空が続くので画面が変わってもつながって見える。
Esc（パッドは ×B）でオープニングへ戻れる。

| 遊び方 | 1P | 2P |
|---|---|---|
| 1人で遊ぶ | 人 | コンピュータ |
| 2人で対戦 | 人 | 人 |
| タイムアタック | 人（記録に挑む） | ― |
| フリープレイ | 人（一人で飛ぶだけ） | ― |
| オプション | ― | ―（設定画面へ） |

- **腕前はここでは選ばない**（2026-08-15 改定）。オプションの「コンピュータの強さ」に
  一本化した ―― 同じ設定を2か所で触れると、どちらが本当か分からなくなる
- 操作は上下で遊び方、Enter で決定・Esc で戻る。
  パッドはスティック上下で選び、**○A で決定・×B で戻る**
- 選んだ遊び方は対戦から戻ってきても残る（すぐ再開できるように）

### オプション（2026-08-13 追加）

ステージ選択の5つ目。設定は `src/settings.ts` の一つのオブジェクトにまとめ、
localStorage（`biplanes.settings`）に変えたそのつど保存する。変えたそばから効く。

**入口・ゲーム設定・コントローラー設定の3枚**（2026-08-13 改定）。
どの画面も **1P と 2P が同時に操作する** ―― カーソルは2本あり、それぞれのパッドが自分のカーソルを動かす。

- **ゲーム設定**（全体で1つ）: 音量・BGM・古いフィルム風の効果・**コンピュータの強さ**・
  勝ちに必要な点・7.7mm の威力・**全開のパワー**・**全開で水温が上がる速さ**
- **コントローラー設定**（1P・2P それぞれ）: 機首の向き・スティックの遊び・**ボタンの割り当て9項目**
  （7.7mm・20mm・ロール左・ロール右・全開・決定・取り消し・中断・やり直し）

キーボードは既定で 1P の列を担当し、**Tab で 2P の列**に移せる（パッド1台でも 2P 側を組めるように）。
機首のスティックと十字キー、キーボードのキーそのものは変えられない。詳細は decisions.md

**コントローラー設定に「振動の強さ」が入る**（2026-08-15 追加）。切 / 弱 / 標準（既定）/ 強で、
1P・2P それぞれ。7.7mm 被弾＝小、水温が赤帯＝中（鳴らし続ける）、撃墜＝大。
`dual-rumble` の高い錘と低い錘を撃ち分ける ―― 弾は高いほうを弾き、爆発は低いほうを効かせる。
Chrome・Edge で動き、Safari では何も起きない。

**ボタンの割り当ては直押し**（2026-08-15 改定）。決定を挟まず、その行で押したボタンが入る。
十字キーの上下だけは項目を選ぶのに使うので割り当てられない。
**重ねられるかは「同じ場面で読むか」で決まる**（`padConflicts`）――
飛行中に読むもの（武器・舵・全開）と、画面で読むもの（決定・取り消し）は別の集まりなので、
20mm と決定が同じ○A に乗っていてよい。中断・やり直しはどちらでも読むので、両方とぶつかる。

**選べる値は `settings.ts` の `CHOICES` にまとめてある**（2026-08-15 改定）。
画面が並べるのも、保存を読むときに通す検査も同じ表を見る ―― 別々に持っていたころは、
画面に出しようのない値（`aiLevel: 4` など）が保存に入っているとそのまま効いてしまっていた。
表から外れた値は、いちばん近いものへ寄せる。

**「全開のパワー」に併記する速度は、飛びの計算そのものから出す**（`levelSpeed`）。
表に書き写すと、飛びの数値をいじったときに表示だけが古いまま残るため。
`node tools/flight-probe.mjs --thrust=300` で、設定を変えずに任意のパワーを測れる。

### 一時停止（2026-08-15 追加）

飛んでいる最中に **＋（Start）／Esc** を押すと止まり、「ゲームを終了しますか？」が出る。
それまでは押した瞬間にタイトルへ戻っていたので、押し間違えると試合が消えていた。

- 止めている間は**何も進まない**（機体・弾・気球・煙・開始の合図）
- カーソルの初めの位置は「いいえ、つづける」。＋・×B・Esc のどれでも戻れる
- エンジン音は絞り、曲は小さくして残す（止めると戻ったとき頭から鳴り直すため）
- 戻るときは **GO! を 0.5 秒**出してから動きだす。出撃位置には戻さない
- 決着が付いたあとは確認を挟まず、そのままタイトルへ戻す

### 開始の合図

**READY? → 3 → 2 → 1 → GO!** の順に約3秒（`COUNT`）。数字ごとに低い音、GO! で高い音。

- 合図の間は**機体を出撃位置で止めて待たせる**。飛ばしたまま待たせると、
  始まる前に落ちたり流されたりしてしまう
- 決着後のやり直し（Enter・○A）にも合図が入る
- 対戦中は Esc（パッドは Start）でタイトルへ戻れる。
  決着後は Enter・○A でやり直し、Esc・×B でタイトルへ

## タイムアタック（2026-08-12 決定・2026-08-15 改定）

**10ステージの合計タイムを競う**モード。敵も武装も出ない。
もとは「プラクティス」という練習の場だったが、遊びの芯はタイムそのものなので
名前も作りもタイムへ寄せた（2026-08-15 改定）。

- **計器盤を出す**。対戦と同じ真鍮の板で、出すものだけ違う ――
  TIME（合計タイム・窓の隅に今のステージ）／ RINGS（のこりの輪）／ 水温計。
  水温計は対戦よりよく見ることになる（全開の使いどころがタイムを決めるため）
- **自爆はタイムに +3 秒**。すぐ出撃位置へ戻れるので、時間で払わせないと
  「落ちたほうが速い」場面ができてしまう。落ちた場所に「+3.00」を出し、
  計器の下に自爆の回数も添える
- 結果には合計タイム・自爆の回数・ハイスコアを並べる

### 輪

- 輪には**くぐる向き**がある。**その向きに輪の面を横切ったときだけ**通過。
  上から乗っても、逆向きに抜けても通らない
- 見た目は**くぐる向きに潰した楕円**。潰れている方向がそのまま入る向きを表す。
  矢印も添えてあるので、形と矢印のどちらでも読める。
  **矢印の鏃は塗りつぶした三角**（2026-08-15 改定）―― 細い線を2本ひげのように
  生やしていたころは、遠目には軸と区別がつかずただの横棒に見えて、向きが読めなかった
- 開口部の半径は機体幅の 0.80 倍（約 82px）。横切った点がこの中に収まれば通過
- 判定は**前のフレームと今のフレームを結んだ線分**が面を越えたかで見る。
  位置だけで見ると輪の中へ入り込めば通ってしまい、横から潜る意味がなくなる。
  線分で見れば速く飛んでも飛び越さない

### 配置

**全ステージ手で組んである**（`src/timeattack/stages.ts` の `STAGES`）。
乱数で作ると「この配置ならこの機動」という狙いが作れず、タイムも比べられない。

輪の位置は**機体が実際に描ける輪の大きさ**に合わせてある。宙返りは 206×321px なので、
折り返しの上下差は 320px 前後、横幅は 200px 前後。これを外すと辿れないコースになる。

| ステージ | 名前 | 輪 | 狙い |
|---|---|---|---|
| 1 | 上昇と下降 | 2 | まっすぐ飛んで上げて下げるだけ |
| 2 | 高度を変える | 3 | 振れ幅を大きく。速度を落とさずに登る／降りる |
| 3 | 折り返す | 3 | 最後だけ左向き。初めての折り返し |
| 4 | 宙返り | 3 | 3つ目が2つ目の後ろで同じ向き。一周して戻るしかない |
| 5 | スプリットS | 3 | 高いところを右へ→低いところを左へ。背面で降りながら回る |
| 6 | インメルマンターン | 3 | 低いところを右へ→高いところを左へ。登りながら回る |
| 7 | 八の字 | 5 | 折り返し2回。左右に振られる |
| 8 | ひと回り | 6 | 輪の向きが道順になった一周コース |
| 9 | 連続旋回 | 8 | ひと回りしてから下の直線へ入り直す |
| 10 | 総仕上げ | 10 | 宙返りを挟んで一周。ここまでの機動を続けて出す |

画面は左右がつながっているので、折り返しは「宙返りで戻る」か「画面を一周する」かを選べる。
近い折り返しは宙返りのほうが速い ―― そこが練習になる。

同じ場所に輪を2つ置かない。番号が重なってどちらを狙うのか読めなくなるため。

### タイム

- 各ステージのタイムを測り、**10ステージの合計がいちばん短いもの**をハイスコアとして
  localStorage に残す（`biplanes.practice.best`）
- 落ちてもすぐ出撃位置に戻すが**時計は止めない**。落ちること自体が損になる

## 得点・勝利条件

- 敵機撃墜: 3点 / 気球: 1点 / 敵の自滅: **無傷なら 1点、傷ついた機体なら 3点**
  （2026-08-15 改定。追い詰められた側がわざと落ちて、相手に入る点を減らす逃げ道を塞ぐため。
  見分けは体力の帯そのもの ―― 目盛りが欠けていれば「傷ついた機体」）。
  **地面への激突とエンジンの焼き付きは同じ扱い**。焼き付きだけ 0 点のままだと、
  そちらが「点を与えずに死ねる道」として残ってしまう
- **20点先取で勝利**（2026-08-12 決定。当初 10点だったが短く感じられたため倍にした。`SCORE.winning`）
- 勝敗が決まると操作を受け付けなくなり、その場で静止する。Enter でやり直し

## 気球

- ランダムな間隔（**4〜11秒**）で画面下からゆっくり上昇し、画面上端で消える。同時に最大**4個**
  （当初は 8〜20秒・最大3個。撃つものがない時間が長かったため増やした。
  気球は上りきるまで 18〜28秒 空にいるので、実際の数を決めているのは上限のほう）
- 7.7mm でも 20mm でも割れる。どちらのプレイヤーが撃ってもその人の得点
- 当たり判定は球皮だけ（籠や索には当たらない）
- 大きさは画面幅の 7.5%（機体は 8%）。上昇は毎秒 34〜54px、左右にゆっくり揺れる
- 割れると小さな火の玉＋黒煙＋布の破片が出る
- **金色のボーナス気球**（2026-08-12 決定）: 撃つと**自機が直る**。
  HP と、被弾で鈍った性能の両方が戻る。得点は通常の気球と同じ1点。
  負けている側の逆転手段になり、試合終盤まで気球を撃つ動機が続く。
  出る割合は 22%（`BALLOON.goldChance`）
- 金色は**色を染めたうえで後光を添える**。染めるだけでは夕焼けの空に埋もれて
  普通の気球と見分けがつかないため。後光は煙の絵を黄色く染めたものを流用する

## 画面・ステージ

- 1画面固定・スクロールなし。16:9（1280×720 論理解像度）
- 機体の表示サイズは画面幅の 8%（1280px 時に約 102px）。煙と発射炎はこれに追従して拡縮する
- 画面左右端はラップアラウンド（本家準拠。2026-08-12 決定）。
  **端からの出しろは機体の半分**（2026-08-13 改定）。もとは機体1つぶん取っていて、
  一周のうち 114px ぶん**姿が完全に消えている時間**ができていた。
  半分にすると、右端で隠れきった瞬間に左端から出てくるので消える時間がなくなる
- **弾も同じところで折り返す**（2026-08-15 改定）。それまでは機体だけが向こう側から出てきて、
  弾は端で消えていた。折り返しの位置は `src/config.ts` の `WRAP` に一本化してある。
  7.7mm の射程（765px）は一周（1382px）より短いので、折り返した弾が自分に戻ってくることはない
- **コンピュータも端をまたいで狙う**（2026-08-15 改定）。それまでは端の向こうにいる相手を
  「画面の反対側にいる遠い相手」と見て、わざわざ長いほうを回っていた
- **地面は x によって高さが変わる**（2026-08-13 改定）。もとは一本の水平線（y = 612）で、
  それだと中央の街のところが屋根の高さの壁になり、街の上を飛ぶと何もない空中で墜ちていた。
  **建物には当たり判定を持たせず**（尖塔も煙突も背景の絵として通り抜ける）、
  地面は建物が立っている谷底＝道の高さに合わせた。数値は `src/config.ts` の `GROUND`

  | x | 地面の y |
  |---|---|
  | 0 | 658 |
  | 200 | 662 |
  | 400〜1000 | 665 |
  | 1120 | 645 |
  | 1280 | 615 |

  街の中央では 612 → 665 で 53px 下がり、尖塔や煙突の間を縫って飛べる。
  右端だけは手前の丘が持ち上がるので、そこに合わせて上げてある
- 天井は壁なし（画面上端は失速で自然に戻される）。地面への激突は自滅
- 背景: 昼の空、雲、遠景の丘、両端に各プレイヤーの飛行場（リスポーン地点）
