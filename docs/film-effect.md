# フィルム風ポストエフェクト設計メモ

ステータス: **採用（強度「弱」・縦キズなし）**。実装は `samples/screen-mock.html` を参照

Cuphead のレトロ感は「絵の描き込み」ではなく、**画面全体にかける古いフィルムの後処理**で作られている。
Bi-Planes でも同じ方式を採る。ゲーム内では Phaser 3 のポストパイプライン（フラグメントシェーダ）として
カメラに1枚かける形で実装するので、ゲームロジックやアセットには一切影響しない。

## 積む層（下から順）

| 層 | 内容 | 目的 |
|---|---|---|
| 1. ソフトフォーカス | 微量のブラー（0.4〜0.9px） | 線のくっきり感を殺し、印刷・映写のにじみを出す |
| 2. トーン | 彩度を落とす + セピア寄せ + コントラスト微減 | 退色したフィルムの色 |
| 3. ハレーション | 明部がにじんで発光する | 古い映写機のにじみ |
| 4. フィルムグレイン | 毎フレーム更新するノイズ（オーバーレイ合成） | 粒状感 |
| ~~5. 縦筋（スクラッチ）~~ | ~~縦に走る明暗の細線~~ | **不採用**。作為的に見えるため 2026-08-12 に外した |
| 6. ゴミ・毛 | 短い曲線や点が一瞬映る | 映写機のゲートのゴミ |
| 7. 露光ゆらぎ | 明るさが微妙に上下する | フリッカー |
| 8. ゲートウィーブ | 画面全体が 1px 未満で揺れる。ときどき縦に飛ぶ | フィルムがゲートで暴れる動き |
| 9. ビネット | 四隅が落ちる | レンズと映写の減光 |

## 効き方の決め事

- **エフェクト層は 24fps 更新**（ゲーム本体は 60fps）。粒とキズだけが古いコマ速で動くことで、
  「映像は滑らかなのに素材が古い」というカートゥーン特有の質感が出る
- 強度はプリセット（切／弱／標準／強）で切り替え可能にし、アクセシビリティ設定として本編にも残す
- **既定は「弱」**。提供イラスト自体が既に古びているため、それ以上かけると絵が潰れる
- `prefers-reduced-motion` の環境ではゆらぎ・ウィーブを止める

## 実装

- サンプル: CSS フィルタ + Canvas オーバーレイ（グレー 128 ベースに overlay 合成）
- 本実装: Phaser 3 `PostFXPipeline`。上記1〜9を1本のフラグメントシェーダにまとめ、
  時間 `uTime` を 1/24 秒単位に量子化して渡す
