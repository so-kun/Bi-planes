## 2026-08-12: M1（1P プレイテスト版）を実装

### やったこと

- プロジェクトを立ち上げ（Phaser 3.90 + TypeScript + Vite）。`npm run dev` で動く
- **自作フライトモデル**を実装（`src/flight.ts`）。推力・重力・揚力・抗力の4力を積分し、
  失速を迎え角で扱う。特別な場合分けなしに「急上昇 → 失速 → 機首が落ちる → 立て直し」が出る
- **ロール操作**を実装。宙返りで左向きになると背面になり、正立に戻すにはロールが要る（実機と同じ）
- 武装2種、気球、爆発（空中・地面）、煙（白い航跡・被弾の黒煙）、HUD、計器表示
- **フィルム風ポストエフェクト**を Phaser の PostFXPipeline（GLSL）として実装。
  時間を 1/24 秒に量子化して渡し、粒とゆらぎだけ古いコマ速で動かす
- 効果音と BGM を Web Audio 合成で移植
- `tools/flight-probe.mjs` を追加。ブラウザなしで水平飛行の速度・失速・宙返りの大きさを測れる

### 調整で分かったこと

- 最初の設定では宙返りの半径が 40px 前後になり、機体（102px）より小さい輪で回っていた。
  重力と揚力を落として 268×272px・3.1秒に調整した
- 舵の効きを速度に比例させると、揚力の項も同じだけ落ちるため、いくら遅くなっても
  迎え角が失速角に届かない。平方根で落とすことで低速でだけ失速に入るようになった
- 煙の発生を「1フレームに1粒」にしていたため、フレームが落ちる環境で軌跡が途切れた。
  取りこぼした分をまとめて出すようにした

### 次にやること

- **ユーザーによるプレイテスト**。操作感（失速の入り方、ロール、スロットル）と効果音の確認
- 感触に応じて `src/config.ts` の数値を調整
- 納得できたら M2（2P対戦・スコア・勝敗）へ

## 2026-08-12: ロール操作と気球を追加（実画面モック Rev.5）

### やったこと

- 追加の原本5点を取り込み（気球、両機の上面図・下面図）。`tools/cutout.py` に
  props/ の出力先を追加し、7枚の機体と気球をまとめて切り抜けるようにした
- **ロール操作を実装**。正立と背面を 0.45秒で入れ替える。
  上面図・下面図を中間コマとして補間する:
  0°=側面 → 90°=上面（翼が開く）→ 180°=側面の上下反転（背面）→ 270°=下面。
  翼の見かけの高さは sin に比例するため、上面図・下面図を縦に潰しながら側面図と入れ替えている。
  当初は入れ替えが緩やかすぎて二重像になったので、切り替えを鋭くした
- **気球を実装**。下からランダムに上昇し、弾が当たると割れる。
  当たり判定は球皮だけ（籠や索には当たらない）。割れると火の玉・黒煙・布の破片が出る
- ロール操作の追加に伴い、操作表に R（P1）と /（P2）を追加

### 未解決（ユーザー対応待ち）

- **上面図・下面図の4枚に煙が焼き込まれている**。煙が上翼の上に重なっているため自動では抜けない。

## 2026-08-12: 実画面モック Rev.4（射程の調整と爆発の作成）

### やったこと

- **7.7mm の軌跡を細く**した（曳光の芯 3px → 1.8px、グロー 8px → 4.5px）
- **射程を分けた**。7.7mm は画面幅の約60%（765px）。あわせて 20mm も見直し、
  当初の設定では横方向の到達距離が 7.7mm とほぼ同じだったため、約37%（480px）に短縮した。
  実測で 7.7mm 59% / 20mm 37% を確認
- **爆発を作成**（空中撃墜・地面への激突の2種類）。火の玉・燃え残り・土煙は、
  提供イラストの煙の絵を色染めして作り、絵柄を機体と揃えた。
  色を乗せるとインクの輪郭線まで同じ色になるので、元絵を掛け合わせて線だけ濃さを戻している
- 爆発の見え方の調整で踏んだ問題と対処:
  - 明るい粒が重なって切り抜きの正方形が見えた → 外周を透明に落として丸めた
  - 丸めすぎてペン画の質感が消えた → 落とす範囲を外周28%に緩めた
  - 火が薄く空に負けた → 同じ絵を4回重ねて不透明度を上げた
  - 火が煙に隠れた → 火を煙より上の層に分け、煙の立ち上がりを遅らせた
  - 火の玉がバラけて団子に見えた → 初速と初期の散らばりを抑えて一塊にした
  - 破片が等速で輪に並んだ → 速さの分布を広げて散らした

### 次にやること

- Rev.4 の判定（7.7mm の軌跡の太さ・射程、爆発の見え方）
- 残る「検討中」項目（バランス数値・スロットル方式・画面端の扱い・ボーナス気球）
- M1（1Pプレイテスト版）の実装
