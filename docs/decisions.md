# 決定事項の記録

このファイルはプロジェクトの確定事項の唯一の記録。これに反する提案・実装はしない。
未決事項は末尾の「検討中」に列挙する。

## 確定済み

### 2026-08-12: プロジェクトの基本方針（ユーザー要件）

- レトロゲーム Bi-Planes のブラウザ版リメイク。本家のシンプルな面白さは引き継ぎ、グラフィックとルールに手を加える
- 2人対戦。二機の飛行機を操縦し、相手を撃墜して得点を競う。規定点数に達したら勝ち
- リアルな操作性（急上昇での失速など）を実現する
- 操作: 上下 + 弾発射（本家準拠）に加え、スロットル操作と2種類の弾（7.7mm / 20mm）
- 耐久力制: 7.7mm は複数発、20mm は一撃で撃墜
- 被弾が増えるとエンジンパワーか旋回力が鈍る。被弾時は煙の演出
- グラフィックはカップヘッド風レトロカトゥーン
- 1画面固定、スクロールなし
- 気球がランダムで上昇し、撃ち落とすと得点
- 実装順: まず1Pのみ操縦できる状態 → プレイテスト → 納得したら残りを実装

### 2026-08-12: 技術スタック

- **Phaser 3 + TypeScript + 自作フライトモデル** を採用
- 理由: 描画・音・入力・シーン管理はエンジンに任せ、揚力・失速などの飛行力学だけ自作する。
  汎用物理エンジン（Matter.js 等）は揚力・失速を扱えず、挟むと操作感のチューニングが難しくなるため不採用

### 2026-08-12: 対戦形態

- **1台のキーボードでローカル2人対戦** を採用（P1: 左手側キー、P2: 矢印+右手側キー）
- ゲームパッド対応・CPU対戦・オンラインは完成後の拡張候補とし、今回のスコープ外

### 2026-08-12: サウンド方式

- **全て Web Audio で合成**（SFX はシンセ合成、BGM は1930年代スウィングジャズ風の自作シーケンス）
- 外部素材を使わず自己完結。ただしサンプルを聴いてユーザーが採用判断する（下記「検討中」参照）

### 2026-08-12: 効果音・BGM（採用）

- サンプル第1号（`samples/art-sound-sample.html`）の **SFX 8種と BGM「Dogfight Rag」の方向性を採用**
- Web Audio によるリアルタイム合成方式で本実装する

### 2026-08-12: アートの方式 — コード描画をやめ、提供イラストのスプライト方式に切替

- ユーザーからアートの完成デザイン（機体2色 + 煙あり版 + ステージ背景）が提供された
- 絵柄は**ヴィンテージのペン画 + 水彩**（細密なハッチング、リベット、星型エンジン、木製支柱、張線）。
  コード描画（SVG/Canvas）では再現不可能な密度のため、**コード描画は廃止**
- **提供イラストをそのままゲーム素材として使う**（スプライト方式）
- 第1号〜第3号のコード描画アートはすべて不採用。ただし第3号の**フィルム風ポストエフェクトは有効**で、
  スプライトの上にかける（強度は下げる。詳細は docs/film-effect.md）
- アセットの仕様・必要ファイルは docs/assets.md に定義

### 2026-08-12: 実画面モック Rev.1 の判定（確定）

- **フィルム処理**: 既定は**「弱」と「標準」の中間**。**縦キズ（フィルムの傷）は不採用**
  ―― 作為的に見えるため。粒状感・ゴミ・露光ゆらぎ・ゲートウィーブ・ビネットは残す
- **ゲートウィーブ**: 現在の量（プリセット「弱」相当）で確定。
  フィルム強度を上げても揺れの量は増やさない（酔いへの配慮。設定でオフにもできる）
- **機体の表示サイズ**: 画面幅の **8%**。煙と発射炎の大きさは機体サイズに追従させる
  （機体だけ縮めると煙が相対的に大きくなり、承認時の見え方が崩れるため）
- **煙**:
  - 通常飛行中も**薄い白煙**を引き、飛行の軌跡が空に残ってしばらくして消える
  - 被弾時の煙は**黒く濃い**。白い軌跡と重なっても被弾が一目でわかる
- **HUD**: クリーム地＋黒枠の意匠を採用
- **武装の弾道**:
  - 7.7mm — 直線・高速（1500 px/秒）・画面全域に届く・連射（毎秒約11発）
  - 20mm — 低速（640 px/秒）・重力で落ちる山なり・射程約 700px・単発
  - どちらも**発射時に機首から炎（マズルフラッシュ）**が出る。20mm は大きく長い炎＋発射煙

### 2026-08-12: 弾道の射程と爆発（確定）

- **7.7mm の軌跡を細く**する（曳光の芯 1.8px・グロー 4.5px）。太いと画面が騒がしくなるため
- **射程を明示的に分ける**。7.7mm は画面幅の約 60%（765px）、20mm は約 37%（480px）。
  20mm は「懐に飛び込んで当てる」武器という位置づけを、数値で保証する
- **爆発は空中撃墜と地面への激突の2種類**を用意する:
  - 空中 — 閃光 → 全方位の火の玉 → 破片が放物線を描く → 黒煙が膨らんで数秒残る
  - 地面 — 火は上半分だけに立ち上がり、土煙が左右に広がる。衝撃波の輪は横長の楕円
- 火・燃え残り・土煙は、**提供イラストの煙の絵を色染めして作る**。別の絵を用意すると絵柄が浮くため。
  染めるとインクの輪郭線まで同じ色になるので、元絵を掛け合わせて線の濃さだけ戻している

### 2026-08-12: ロール操作と気球（追加）

- **ロール操作を追加**する。押すと機軸まわりに180度回り、正立と背面が入れ替わる（0.45秒）
- 見た目は提供いただいた**上面図・下面図を中間コマとして補間**する
  （0°側面 → 90°上面 → 180°側面の上下反転 → 270°下面）
- 操作キーは P1 = R、P2 = /
- **気球**は画面幅の 7.5%。下からランダムに上昇し、7.7mm でも 20mm でも割れる。
  当たり判定は球皮だけ（籠や索には当たらない）
